# MERN Stack Journey 🚀

This repository documents my journey of learning and practicing the **MERN Stack** through consistent, hands-on development.

The intention behind this repository is not just to follow tutorials, but to **understand how the different parts of a modern full-stack application work together** by learning concepts, implementing them, experimenting with them, and building along the way.

## 📌 Prerequisites

A basic understanding of the following is assumed before going through this repository:

* HTML
* CSS
* JavaScript
* Basic Git & GitHub
* Basic programming concepts

This repository focuses on the technologies and concepts built **on top of these fundamentals**, particularly the MERN stack.

## 🛠️ What This Repository Covers

The journey will gradually explore:

* **MongoDB** — Database
* **Express.js** — Backend framework
* **React** — Frontend library
* **Node.js** — JavaScript runtime

Along the way, I will also work with concepts such as:

* REST APIs
* Frontend ↔ Backend communication
* CRUD operations
* Middleware
* Authentication & Authorization
* JWT
* Database modeling
* Mongoose
* Error handling
* Full-stack application architecture
* Deployment

## 📖 How I'm Learning

The repository follows a **learn → practice → build → document** approach.

Each day, I will learn a concept and implement it rather than simply reading about it. The code and notes in this repository represent my understanding at that point in the journey.

The earlier days may contain simple examples and experiments, while later days will gradually evolve into more complete applications.

## 📂 Structure

```text
MERN STACK JOURNEY/
│
├── day-01/
├── day-02/
├── day-03/
├── ...
│
└── README.md
```

Each `day-*` folder represents a step in the learning process and contains the work completed during that stage.

## 🎯 Intention

This repository is a **public record of my learning process**.

I want to be able to look back at it and see not only the projects I built, but also the progression from understanding individual concepts to being able to combine them into complete full-stack applications.

There will be bugs, failed approaches, experiments, and imperfect code.

That's part of the process.

> **Learn the concept. Write the code. Break it. Understand why. Fix it. Move forward.**
