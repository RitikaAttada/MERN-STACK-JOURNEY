# DAY-06: Introduction to node.js

### what is node.js?

node.js is an open-source java script runtime environment. So, basically it helps run javascript outside the browser.  

A Node.js app runs in a single process, without creating a new thread for every request. Libraries in node.js are written in non-blocking paradigms.So when node.js performs an I/O operation, instead of blocking, it resumes operation when the response comes back.  

This allows node.js to handle thousands of concurrent connections with a single server instead of handling many threads, which could lead to significant amount of bugs.

The following concepts are key to understand asynhronous programming, which is one of the funcdamental parts of node.js
   1. Asynchronous programming and callbacks
   2. Timers
   3. Promises
   4. Async and Await
   5. closures
   6. The Event Loop
